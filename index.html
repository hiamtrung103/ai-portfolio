01RAG: bringing data into contextAI SYSTEMS · CONCEPT NOTE+

Retrieval-Augmented Generation adds a search step before generating an answer. A typical system splits documents into passages, indexes them, retrieves relevant passages, and includes them in the model’s context.

The model is only part of the picture. Chunking, retrieval quality, and source verification all affect the result. Having reference material does not guarantee a correct answer.

Documents → Index → Retrieve → Context → Answer
Read the original paper ↗
02Local-first: keeping data closeSOFTWARE DESIGN · CONCEPT NOTE+

Local-first tools prioritize storing data and performing core operations on the user’s device. This can reduce latency and keep software useful when the network is unreliable.

Storage, backups, and synchronization across devices still need careful design. The approach fits many repository analysis tools, but its trade-offs depend on the product.

Read about local-first software ↗
03Reading architecture through dependenciesDEVELOPER TOOLS · CONCEPT NOTE+

Each module becomes a node, and each import becomes a directed edge. The graph reveals widely used modules, closely connected clusters, and cycles that are hard to spot by reading files individually.

Static graphs have limits: dynamic imports and runtime configuration can leave parts of the picture incomplete. Interpret the graph in the context of the project rather than relying on connection counts alone.
